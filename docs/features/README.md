# Feature maps

Built from `knowledge/flow-digest.md` (guest crawl 2026-10-09, desktop kumparan.com + mobile m.kumparan.com). Signed-in paths are out of scope: signing in needs a person at Cloudflare's check. Test-idea sections list the automated case IDs (updated 2026-10-11).

- [auth.md](auth.md): login form, alternative sign-in, recovery and register links, bot challenge.
- [article.md](article.md): story page, breadcrumb, channel, author, topic, editors, organisation info.
- [like.md](like.md): like button; guest is redirected to login.
- [comment.md](comment.md): story comment thread; guest can draft but not send.
- [report.md](report.md): "Laporkan Konten" form with six reasons; never submitted.
- [share.md](share.md): share bar and share menu (not in the digest; from page objects and specs).
- [search.md](search.md): search entry, result tabs, sort, result cards.
- [navigation.md](navigation.md): header, mobile burger menu and bottom nav, channel/trending/topic routes.
